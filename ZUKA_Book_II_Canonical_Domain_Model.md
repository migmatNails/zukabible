# Chapter 2 — Entity Theory

## Constitutional Definition

An Entity is any uniquely identifiable participant, object, concept, or institution recognized by the platform.

## Entity Properties

Every entity possesses:

- Identity
- Lifecycle
- Relationships
- Events
- State
- History

---

# Chapter 3 — Core Entity Registry

## Tier-0 Constitutional Entities

### Identity
Who participates.

### Relationship
How participants connect.

### Memory
What participation leaves behind.

### Trust
Confidence earned through participation.

### Community
Networks formed through participation.

### Opportunity
Potential value creation pathways.

These entities are constitutionally protected.

---

# Chapter 4 — Event Theory

## Constitutional Definition

An Event is a recorded occurrence affecting one or more entities.

Examples:

- Joined Community
- Attended Gathering
- Created Memory
- Earned Trust
- Received Opportunity

## Event Principles

- Immutable
- Auditable
- Timestamped
- Traceable

---

# Chapter 5 — Relationship Theory

Relationships are first-class entities.

A relationship may exist between:

- Person ↔ Person
- Person ↔ Community
- Community ↔ Community
- Organization ↔ Organization
- Person ↔ Opportunity

Relationship strength evolves through participation.

# Chapter 6 — Time Theory

Time is a foundational dimension.

All entities possess:

- Creation Time
- Modification Time
- Historical State
- Future Potential State

Historical continuity must be preserved.

# Chapter 7 — Domain Boundaries

Owns connections.

Trust Domain

Owns collective participation.

Opportunity Domain

# Chapter 8 — Entity Lifecycles

Identity:
Creation → Verification → Participation → Legacy

Memory:

Community:

Earned → Strengthened → Maintained → Decayed/Recovered
