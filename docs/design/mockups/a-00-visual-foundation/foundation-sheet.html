6 · Motion — "Motion as Information" LOCKED · founder-approved 2026-07-16

Calm, instant infrastructure by default; motion is reserved for liveness. This page honours your OS reduce-motion setting — flip it on and every demo below freezes to a static frame.

TierMeaningTokensDemo
T0 · structurenavigation, tabs, chrome — silent or near-instant instant (0ms)no demo — that's the point
T1 · feedbacktouch response, skeletons, route pushes (Feed → Detail = 280ms) quick 120 · standard 200 · route 280 · routeBack 220
T2 · lifethe ONLY expressive motion — LIVE pulse, the Pulse count bloom 700 · easeOutBack LIVE NOW

Never-list

Money and trust surfaces never animate (instant) · bloom on a non-life surface = the same violation class as decorative coral · motion never gates a sacred proof (transitions interruptible; the 3-tap path never waits) · no stagger cascades on lists · opacity+transform only · everything collapses under reduce-motion.

Session self-check (Constitution §7)

States: all six rendered · Sacred proofs: untouched (sheet is not a flow) · Terminology: Gathering/Person, trust never numeric · Money: UGX integer format only · Coral: LIVE contexts only (pill, dot, tier demo) · Contrast: body ink5 on midnight ≈ 15:1, secondary ink3 used ≥14px only · 360×800: card columns are 360px · Data: all fields exist in the feed RPC (title, venue, distance, time, count, price, status) · No dark patterns: honest counts, no fake urgency · Expressive layer: presented as 3 named variants, not silently locked.
