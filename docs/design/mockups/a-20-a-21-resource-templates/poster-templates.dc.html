A-20 · 04
Content edge cases
TITLE AT MAX LENGTH · 60/60 CHARS Input is capped at 60 chars; the layout clamps at 4 lines with an ellipsis as a belt-and-braces rule.
VERY LONG VENUE NAME Truncation strategy: venue is always one line with an ellipsis — never wraps, never pushes the price row. The full name lives on the Detail page below the poster.
A-20 · 05
Required states
LOADING · STATIC SKELETON No shimmer — templates never animate. Blocks mirror the final layout so nothing jumps.
EMPTY · NO TEMPLATE CHOSEN
No poster — and that's fine The Detail page renders heroless from plain Gathering data. Choosing a template sits behind go-live and never blocks publishing.
Sacred proof: 60-second Go Live is untouched.
OFFLINECACHED RENDER
All text renders from cached Gathering data. If the photo isn't cached, the template falls back to the photo-less composition — identical, complete, no spinner.
ERROR · PHOTO FAILEDGRACEFUL FALLBACK
hero_photo failed to load → render the photo-less composition. There is no broken-image state and no error chrome on the poster itself.
SUCCESSPOSTER ATTACHED
"Poster attached to the Gathering." Confirmation is instant — no celebratory animation; success green lives in the app chrome, never inside the template.
