A-13 · Compact list rows — the canonical two-line grammar

1 · GRAMMAR + SEARCH CONTEXT — line 1: title + right-aligned fact; line 2: context + state chip. Spine = state.

Right-aligned fact slot is context-owned: distance in search/map, time in tickets, nothing in inbox. One chip max — a row is a glance, not a card.
