## The Three Constitutional Proofs (Volume XXII, Ch.1)

These are not aspirations. They are testable pass/fail criteria.

```
PROOF 1 — 60-SECOND GO LIVE
  Starts: organiser taps "Go Live"
  Ends:   venue pin visible on another device's feed
  Passes: elapsed time ≤ 60 seconds on 3G

PROOF 2 — ZERO-FRICTION DISCOVERY
  Starts: person opens ZUKA for the first time
  Ends:   they can see at least one live or soon event
  Passes: zero additional actions required (no login wall, no signup gate)

PROOF 3 — 3-TAP TICKET PURCHASE
  Starts: person is on a gathering's detail view
  Ends:   ticket confirmed in their possession
  Passes: tap count ≤ 3 on a returning user with saved payment method
  Three taps: (1) Buy Ticket → (2) Pay with saved method → (3) Confirm
```

## Invisible Sophistication Principle (Volume XIV; Volume XXII, Ch.2)

The more sophisticated ZUKA becomes internally, the simpler it must become externally.

```
RULE 1  3-5 taps maximum for any core action
RULE 2  Most actions complete in under 30 seconds
RULE 3  AI is invisible — no "AI-powered" labels; intelligence surfaces as natural outcomes
RULE 4  Progressive disclosure — show only what the person needs right now
```

## The Notification Constitution (Volume XXII, Ch.3-4)

Six permitted categories:
```
1. Transactional      — ticket, payment, transfer confirmations (non-configurable)
2. Safety-Critical    — account security, OTP (non-configurable)
3. Gathering Reminders — event starting, doors open, post-event memory prompt (configurable)
4. Social             — tagged in Memory, friend attending (configurable, granular)
5. Discovery          — "something happening near you" (configurable; max 2/day)
6. Anniversary        — "on this day" Memory prompts (configurable; grief-sensitive)
```

Four timing rules:
- No engagement-optimised timing (ever)
- No Categories 3-6 between 10PM-7AM local time
- Batch multiple notifications from the same window into one
- Grief/sadness Memories: afternoon delivery only (2PM-5PM)

## The Anti-Dark-Pattern Constitution (Volume XXII, Ch.5)

Eight prohibited UX patterns — no exceptions without founder sign-off:

```
P1 Fabricated Social Proof    — no estimated/manufactured "127 people viewing"
P2 Involuntary Social Sharing  — no default-on sharing of personal actions
P3 Emotional Manipulation      — no using grief/emotion data to manufacture urgency
P4 Consent Dark Patterns       — no pre-ticked boxes, no double-negatives
P5 Artificial Scarcity         — countdown timers only for genuine constraints
P6 Deletion Obstacles          — account deletion reachable in ≤ 3 taps
P7 Addiction-Pattern Design    — no infinite scroll in Archives; no variable-ratio rewards
P8 Pricing Obfuscation         — full price (including fees) visible before commitment
```
