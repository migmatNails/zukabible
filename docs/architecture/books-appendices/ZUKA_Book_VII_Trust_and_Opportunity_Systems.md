## Constitutional Premise

Trust is confidence established through observed participation and historical
behaviour. (Zuka-Bible 2, Book I Part B, Ch.8.1)

Opportunity is the possibility of value creation emerging from trust, participation,
relationships, and communities. (Zuka-Bible 2, Book I Part B, Ch.10.1)

The pipeline that connects them (Volume XIII, Ch.10):
```
Participation → Trust → Reputation → Visibility → Opportunities → Value Creation
```

## Opportunity Architecture Summary

**Four Opportunity Engines** (Volume XV):

```
Sponsorship Engine   — Brand → Event/Community/Creator matching
                       CRL minimum: 'assisting'; NEVER autonomous
Mentorship Engine    — Mentor → Student matching via shared community
                       CRL minimum: 'advising'
Scholarship Engine   — Community-funded scholarship distribution
                       CRL 'coordinating' ONLY for automated distribution;
                       committee-review path available earlier
Creator Economy      — Creator Persona → Booking opportunity matching
                       CRL minimum: 'advising'
```

All four engines inherit Volume VIII, Ch.22's unconditional stricter provenance bar:
every match output carries a complete ProvenanceRecord before it reaches any party.

**Trust → Opportunity Dependency** (Volume VII, Ch.20; ADR-004):
The Opportunity domain CANNOT advance to DRL 2 until the Trust domain is at DRL 2+.
This dependency is constitutional and cannot be waived.
