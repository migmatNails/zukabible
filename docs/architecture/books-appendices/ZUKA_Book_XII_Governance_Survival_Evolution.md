## Five Governance Councils (Governance Council Framework document)

```
Architecture Council  — structural decisions, ADRs, feature proposals, stage transitions
Trust Council         — trust model, fraud thresholds, appeals changes
Security Council      — access control, data security, breach response
Governance Council    — legal compliance, market addenda, Legal Review Queue items
Evolution Council     — constitutional amendments, zone reclassifications, new volumes
```

At solo-founder stage: the founder constitutes all five councils. The value is not
headcount — it is the documented review framework applied consistently.

## Preserve-and-Freeze Protocol (Volume XVIII, Ch.2)

Six dispute types, each with maximum freeze periods:

```
Community Fragmentation   90 days    Political Capture   NO DEFAULT
Leadership Contest         60 days    Cross-Community     60 days
Archive Ownership          30 days    Financial Asset     90 days
```

What is NEVER frozen:
Member read access | Gathering attendance | Memory creation | Individual data portability

Legal hold flag: suspends the maximum freeze period when a valid legal process is received.
