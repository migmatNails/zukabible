## Chapter 1 — The Constitutional Premise

A community is a persistent network of relationships organised around shared
participation. Communities are the fundamental coordination units of civilisation.

```
Gatherings create communities.
Communities create trust.
Trust creates opportunities.
Opportunities create economies.
```

### Recognition Before Creation (contradiction resolved)

The Architecture Audit established: **communities are discovered before they are
created.** Many communities already exist in the world (a church choir, an alumni
network, a neighbourhood). ZUKA recognises the dense relationship cluster first
(via the Community Formation Engine, Volume 09), then offers to formalise it. ZUKA
does not manufacture communities; it recognises and equips them.

### The Four Community Principles

```
SOVEREIGNTY  Every community owns its identity, history, traditions,
             governance, and knowledge.
CONTINUITY   Communities survive leadership changes. Knowledge never disappears.
MEMORY       Every community accumulates memories, stories, traditions,
             knowledge — these become community assets.
INVISIBLE    Complex internally, simple community experience externally.
SOPHISTICATION
```

## Chapter 3 — The Five-Stage Community Lifecycle

```
Formation → Growth → Maturity → Transformation → Legacy
```

The **Transformation** stage is real and must never be omitted — it is the period of
leadership succession, restructuring, or difficulty that mature communities pass
through. The simpler four-stage summary (Formation → Growth → Institution → Legacy) is
acceptable for external communication; the five-stage model is the operative
specification.

## Chapter 6 — The Four-Layer Governance Model

Explicitly decoupled — no single event triggers all-or-nothing succession:

```
OPERATIONAL LAYER  Day-to-day (scheduling, routine comms)
                   Authority: any active leadership role
FINANCIAL LAYER    Budget, treasury, fundraising
                   Authority: Treasurer + governance consensus
HISTORICAL LAYER   What is preserved and how
                   Authority: Archivist (sole constitutional owner)
STRATEGIC LAYER    Governance changes, federation, dissolution, Twin/AI consent
                   Authority: community-wide ratification

Decision models: elder_consensus · founder_authority · membership_election ·
                 committee_vote · archivist_authority (historical only)
```

## Chapter 7 — The Community Trust Profile

Six dimensions — parallel to but distinct from individual TrustProfile:

```
community_reliability · community_authenticity · community_safety ·
community_inclusion · community_continuity · community_stewardship
```

Trust inheritance: a new member inherits a temporary baseline from a high-trust
community — never a permanent transfer (Volume 11, Chapter 8).

## Chapter 8 — Community Succession (the core guarantee)

**Communities outlive individuals.** Succession is DECOUPLED into four independent
chains, each resolving separately:

```
Leadership succession  → governance model's own process
Archive stewardship    → Archivist role transfer
Financial custody      → Treasurer role transfer
Tradition stewardship  → passed to named stewards per tradition
```

No single death, dispute, or departure collapses a community. Each chain is independent.

## Chapter 11 — Community Quality Metrics (anti-fragmentation)

The Reconciliation Audit named Community Fragmentation as a failure mode. The
countermeasure is Community Quality Metrics — measured by density, not size:

```
Participation Density · Trust Density · Continuity ·
```

## Chapter 12 — Community Dispute Governance (Preserve-and-Freeze)

Six institutional dispute types (full detail Volume 23). ZUKA's role is always
**Preserve-and-Freeze, never arbitrate:**

```
Community Fragmentation (90d) · Leadership Contest (60d) ·
Archive Ownership (30d) · Financial Asset (90d) ·
Political Capture (no default) · Cross-Community (60d)

NEVER frozen: member read access · gathering attendance ·
              memory creation · individual data portability
```
