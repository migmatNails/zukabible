## Chapter 6 — The Four Opportunity Engines

```
SPONSORSHIP ENGINE  Brand → Event/Community/Creator matching
                    CRL: 'assisting' minimum. NEVER autonomous.
MENTORSHIP ENGINE   Mentor → Student via shared community
                    CRL: 'advising' minimum. Relationship formation stays human.
SCHOLARSHIP ENGINE  Community-funded distribution
                    Committee-review path early; automated distribution requires
                    CRL 'coordinating' + dispute-free track record.
CREATOR ECONOMY     Creator Persona → Booking opportunity
                    CRL: 'advising' minimum. Negotiation stays human.

All four carry a complete ProvenanceRecord on every match before it reaches any
party (the stricter provenance bar).
```

## Chapter 9 — The Economic Constitution (embodied here)

The Reconciliation Audit named a missing Economic Constitution. Its three doctrines:

```
VALUE CREATION      Value originates from participation, trust, and coordination —
                    never from extraction or attention-harvesting.
VALUE DISTRIBUTION  Value flows to those who created it: organisers paid in <72h,
                    creators matched on merit, communities retain their economy.
VALUE PROTECTION    Anti-fraud (Volume 11), provenance on every match, and the
                    anti-drain principles (Volume 23) protect value from capture.

Compounding before extraction: create value first; monetise second. (Volume 23.)
```
