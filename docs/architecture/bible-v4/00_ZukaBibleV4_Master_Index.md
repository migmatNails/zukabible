## The Two Readiness Axes (govern everything)

```
DRL — Data Readiness Level: can a capability EXIST?
  DRL 0  Schemas only
  DRL 1  Collection (FORBIDDEN: predictions, trust scoring)
  DRL 2  Pattern detection
  DRL 3  Confidence / explainable scoring
  DRL 4  Automation
  DRL 5  Intelligence

CRL — Capability Readiness Level: how DEEPLY should it manifest?
  Observing → Learning → Advising → Assisting → Coordinating → Intelligence

GOVERNING INEQUALITY:
  manifestation_depth ≤ min(DRL_permits, CRL_earned)
```
