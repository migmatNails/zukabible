## Chapter 3 — Community Dispute Framework (Preserve-and-Freeze)

Six dispute types; ZUKA's role is always to preserve and freeze, never arbitrate:

```
TYPE                     MAX FREEZE   DEFAULT RESOLUTION
Community Fragmentation  90 days      Apply configured SuccessionPolicy
Leadership Contest        60 days      Apply governance decision_model
Archive Ownership         30 days      Archivist's documented decision
Financial Asset           90 days      Per applicable market law
Political Capture         NO DEFAULT   External resolution only
Cross-Community           60 days      Revert to last uncontested state

NEVER frozen: member read access · gathering attendance · memory creation ·
              individual data portability
Legal-hold flag suspends the freeze period when valid legal process is received.
```

## Chapter 9 — The Anti-Drain Principles (non-negotiable)

```
1. Free events are always free to list. Permanently. Publicly stated.
2. Users never pay to browse, discover, or view.
3. Convenience fees disclosed upfront before commit — never at confirmation.
4. Pulse Points never expire while the account is active.
5. Ad load capped at 1 promoted per 10 organic in any feed.
6. Subscription prices publicly listed; never changed without 90 days notice.
7. Organiser payout within 48-72h of sale — not after event end.
```
