## Chapter 4 — The Dormant Capability Doctrine

```
Architected does not mean activated.

A capability activates only when ALL FIVE conditions are met:
  1. DRL permits (five-dimension assessment cleared)
  2. CRL permits (earned independently)
  3. Governance permits (relevant Council review)
  4. Trust safeguards exist (anti-fraud operational)
  5. Experience safeguards exist (notification + dark-pattern rules enforced)

No capability activates solely because the technology exists.
Readiness must precede activation.
```
