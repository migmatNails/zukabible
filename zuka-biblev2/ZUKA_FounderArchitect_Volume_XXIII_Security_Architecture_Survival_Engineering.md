Protect identities, communities, trust, opportunities and data.

- Zero Trust
- Defense in Depth
- Least Privilege
- Secure by Default
- Audit Everything

Protection Layers:
1. Infrastructure Security
2. Application Security
3. Identity Security
4. Data Security
5. Community Security
6. Economic Security

Founder Rule:
