## Mission

Data is the most strategic asset within ZUKA.

Applications can be rebuilt.
Services can be replaced.

History, relationships, trust and knowledge cannot be recreated once lost.

# Data Constitution

## Principle of Data Sanctity

Data is collected intentionally.

Every data point must answer:

- Why are we collecting it?
- Which domain owns it?
- Which future systems require it?
- Which DRL and CRL levels depend on it?
