
# Volume XIV — Capability Readiness Architecture (CRL/MRL)

Mission: Fair adaptive capability activation.

Core Principle:
The more sophisticated ZUKA becomes internally, the simpler it becomes externally.

DRL:
Determines whether a capability can exist.

CRL:
Determines how deeply a capability manifests.

Readiness Domains:
- Identity
- Community
- Gathering
- City
- Country
- Platform

Capability States:
Observing → Learning → Advising → Assisting → Coordinating → Intelligence

Constitution:
Capabilities activate through readiness, not privilege.
